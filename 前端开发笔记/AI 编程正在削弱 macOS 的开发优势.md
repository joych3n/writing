# AI 编程正在削弱 macOS 的开发优势

我平时 macOS 和 Windows 都用来开发。以前我更偏向 macOS，因为它系统流畅、软件生态好，终端和类 Unix 环境也更适合开发。尤其做前端时，macOS 给我的感觉一直是省心、稳定、顺手。

但这两年我的感受发生了一些变化。

现在越来越多开发工作开始依赖 AI。以前环境配置报错、命令不会写、工程问题需要慢慢查资料，现在很多时候把问题丢给 AI，就能快速得到方向。AI 在一定程度上抹平了不同系统之间的开发体验差距。

与此同时，Windows 的开发环境也成熟了很多。WSL、Windows Terminal、VS Code、Docker 等工具已经让 Windows 的开发体验明显提升。再加上 AI 编程工具的辅助，过去 macOS 在编程上的一些优势，现在没那么突出。

当然，macOS 依然很好用，特别是在系统体验、苹果生态、设计工具和 iOS 开发方面仍有优势。但如果只是从 Web 开发、前端开发的角度看，它已经不再像以前那样是明显更优的选择。

我现在越来越觉得，真正影响开发效率的，不只是用 Mac 还是 Windows，而是项目结构是否清晰、工具链是否顺手，以及能不能高质量地和 AI 协作。

所以我的看法变得更务实了：macOS 依然优秀，但在 AI 编程时代，它作为开发系统的独特优势正在减少。
